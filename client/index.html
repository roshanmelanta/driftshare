How it works

  1. The sender opens a connection. Their browser generates a short share code and waits.
  2. The receiver enters the code. The two browsers use a small relay just to introduce themselves — no file data touches it.
  3. The browsers connect directly. Once linked, the file streams straight from one device to the other, encrypted end to end.

Built with WebRTC. Files never touch a server.
